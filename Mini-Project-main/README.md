# Gatherly - Campus Event & Student Organization Platform

High-energy campus community app built with React 19, TypeScript, Tailwind CSS v4, and Lucide Icons.

## Quick Start (Run Locally)

1. **Install dependencies**:
```bash
npm install
```

2. **Start the local development server**:
```bash
npm run dev
```

3. Open `http://localhost:5173` or `http://localhost:3000` in your browser.

## Project Structure
- `src/components/screens/`: All 7 core screens (Login, Organizer Dashboard, Student Portal, Event Creation, Event Preparation, Organization Setup, Settings).
- `src/components/modals/`: Digital QR Gate Pass modal, task creation dialog.
- `src/components/DeviceFrame.tsx`: Toggleable mobile device chassis & responsive wide display.
- `src/data/mockData.ts`: Sample events, attendees, milestones, telemetry metrics, and core team members.
