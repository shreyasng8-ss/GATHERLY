# Gatherly - Backend Architecture & Setup Guide

This document describes the backend architecture, JSON persistent storage, REST API endpoints, testing procedures, and operational details for the **Gatherly** campus event management platform.

Please see `Mini-Project-main/BACKEND_SETUP.md` for the full setup guide, API reference, test commands, and architectural documentation.

### Quick Start:
```bash
cd Mini-Project-main
npm install
npm run dev
```

- **Frontend**: `http://localhost:5173`
- **Backend API**: `http://localhost:5000`
- **Health Check**: `http://localhost:5000/api/health`
- **Events Endpoint**: `http://localhost:5000/api/events`
